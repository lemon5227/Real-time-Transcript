# 拾句项目路线图

**更新时间：** 2026-09-24
**权威状态来源：** 本文件。旧的详细设计和实施计划用于追溯设计、测试与实现过程；它们的原始步骤清单不再代表当前进度。

## 产品目标与边界

拾句面向主要使用中文的留学生，帮助他们跟上英文课程，并在课后回听、校正和复习。产品优先在本机保存课堂原声和笔记；本地模型优先，云端能力必须清楚展示并由用户配置。

`Real-time-Transcript` 负责实时转录、课堂记录和课后复习。独立的生成式 AI 字幕项目不作为运行依赖，不合并进本仓库。macOS / MLX 是当前实际验证重点；Windows/CUDA 与云端转录的真实设备测试按用户决定暂缓。

## 状态定义

- **已实现**：代码和自动化测试已覆盖；不代表每个平台都完成了真机验收。
- **待真实验证**：主要实现和自动化测试已有，但尚未在目标设备、实际安装包或真实课堂流程中完整跑通。
- **暂缓**：用户明确要求先搁置，或目前缺少目标设备/服务条件；不计作已完成。
- **候选项**：来自既有设计或使用反馈，但还未作为近期交付承诺。

## 下一步验收顺序

### P0：在当前 Apple Silicon Mac 验收安装与课堂闭环

1. **部分通过（2026-09-13）**：最新 DMG 挂载后可启动，健康检查通过且能复用已存在模型。待从 Finder 安装到 Applications 后再次验证；旧安装未被覆盖。
2. **未通过，需重测**：麦克风在模型准备期间已开始收音，模型启动后实时字幕会出现，课堂记录也显示已保存；但录制约 2 分钟时只有约 52 秒字幕时间，并提示跳过音频，且识别内容与 YouTube MLflow 字幕不符。这次不计为准确率或实时性能通过。当前系统默认输入/输出是 MacBook 内置麦克风/扬声器；需先隔离其他音源，再做对齐测试。

   > **2026-09-22 补充（只覆盖其中一半）**：转录管线本身已用**保存下来的**真实课堂录音（127.3s）单独验证——
   > 按原速回放，字幕基本贴着实时边界出现，`丢弃=0.00s`，无错误，详见 [`LATENCY.md`](LATENCY.md)。
   > 但回放是把音频直接推给 socket，**绕过了麦克风采集**，所以上面那条"录音 2 分钟只有 52 秒字幕 /
   > 提示跳过音频"的现象既没有被复现也没有被修复，仍需在隔离音源的条件下重测。本条**仍未通过**。
   >
   > **2026-09-23 补充**：解码器已换成滑窗批处理，并且长跑实测（10.6 分钟、317 次窗口解码）
   > **0 次超过 2 秒步长**、内存平稳，所以"处理跟不上录音"的容量问题不再是解释这一现象的候选原因；
   > 采集链路本身也离线核对过（48k→16k 逐块重采样相对单次重采样 46.3 dB SNR，跑模型后词一致率 95.3%）。
   > 但这两项都**不覆盖真实麦克风**（设备授权、实际设备采样率、回声消除/降噪对语音的影响），
   > 所以本条仍需真机重测，**不要因为管线通过了就把它当作已通过**。
   >
   > 重测时优先看这三行日志，它们能把"是采集问题还是模型问题"分开：
   >
   > ```bash
   > grep "会话结束" logs/realtime-transcript.log   # 实时倍率 / 丢弃 / 静音跳过
   > grep "解码偏慢" logs/realtime-transcript.log   # 是否真的跟不上
   > grep "确认字幕" logs/realtime-transcript.log | tail -1   # 末条字幕覆盖到录音的第几秒
   > ```
   >
   > 先确认 `sysctl vm.swapusage` 有余量（模型需要约 2.3GB），否则会把内存压力误判成采集缺陷。
3. 在复习页回听并点击时间戳，检查音频与字幕定位；检查编辑、笔记、重点、搜索及导出是否保留。
4. 用同一条真实录音运行精细转录，确认完成后自动显示精细稿、实时稿仍可切回；再验证选择字幕、Microsoft 翻译和失败提示。
5. 在同一段英文课程录音上确认说话人标签是否稳定、是否会晚到但不重复字幕；比较开启/关闭 Nemotron 时 Parakeet 的实时倍率。

以上需要真实课堂记录和已配置的翻译服务。完成自动化测试不能替代这些验收。

### 本轮实测说明（2026-09-13）

- DMG 缓存重复下载的根因是启动器把 Hugging Face 缓存默认重定向到应用专属目录。默认值已改为共享 Hugging Face 缓存；自动化测试与修复版 DMG 启动验证通过。已删除测试产生的应用专用 Parakeet 副本（约 2.3GB），保留 `~/.cache/huggingface/hub` 中的原模型；运行中的修复版 DMG 仍可识别共享模型并报告 `ready`。
- 本轮录音结果与指定视频字幕不一致，可能存在其他播放音源干扰或输入问题；没有据此下结论称模型识别准确，也没有继续录音。Microsoft Translator 在当前安装环境仍未配置凭据，翻译实测未完成。

本次已把默认翻译说明改为 Microsoft，并标明 Google 无 Key 公共通道不可靠。今后翻译默认、安装行为或设备支持变化时，同步更新本文件及用户指南。

## 暂缓项

- **Windows/CUDA 和其他 Windows 设备的端到端验收**：代码路径保留；等用户有目标设备再验证，不以 Mac 测试代替。
- **云端转录实测**：接口和配置路径保留；按用户决定暂缓真实服务/设备测试。
- **iPhone 作为额外麦克风的专门集成**：当前先使用浏览器已有的麦克风选择能力；除非实际课堂证明不够用，否则不单独开发设备联动。

## 后续候选项（非近期承诺）

- 从已标记重点和课堂笔记生成轻量“本节重点”复习摘要。只有完成当前回听与精细稿验收后，再确定摘要是否值得进入近期版本。
- 为 Nemotron 增加设置页中的显式预下载/删除/进度管理；当前先依赖 FluidAudio 的共享缓存，避免把 CoreML 权重复制进 DMG。
