# Detailed plans index

The current, user-facing status of project work lives in [`../../ROADMAP.md`](../../ROADMAP.md).

Files in this directory preserve the detailed design and execution recipes used for individual slices of work. Their original checkboxes may be incomplete or stale because implementation, automated verification, and real-device acceptance happened across later commits and sessions. Do not interpret an unchecked box here as proof that code is missing, or a completed implementation step as proof that a real device was tested. Use the roadmap's separate **implemented**, **needs real-world validation**, and **deferred** states.
