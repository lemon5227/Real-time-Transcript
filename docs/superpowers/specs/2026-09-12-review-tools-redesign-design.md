# 课后复习工具栏与字幕操作重规划

- 日期：2026-09-12
- 状态：实现已落地；自动化检查通过，真实课堂浏览器验收见[项目路线图](../../ROADMAP.md)
- 范围：课后复习页的精细转录、翻译和逐句操作；实时课堂翻译默认服务

## 背景

课后复习的核心任务是回听原声、阅读字幕、定位没有听懂的句子并补充理解。当前页面把“课后精细转录”和“翻译”分别做成大卡片，配置项和操作按钮过多，字幕正文被推到页面下方。每句字幕右上角的“选择、译本句、标记重点”也采用了三种不同的控件表达，字号小、对齐弱、状态不够明显。

本次重规划保留现有左右课堂库与详情布局，不改变本地课堂数据模型、原声存储、精细转录接口或翻译接口；只调整详情页的信息层级和交互表现，并将 Microsoft Translator 设为翻译服务默认值。

## 目标与非目标

### 目标

1. 让字幕阅读成为进入课堂详情后的第一视觉和交互主线。
2. 用两个等高、轻量的工具模块承载“字幕版本”和“翻译”。
3. 精细转录完成后自动切换到精细稿，同时保留实时稿作为对照。
4. 让逐句选择、翻译、重点标记拥有一致的尺寸、间距和状态反馈。
5. 新用户默认使用 Microsoft Translator，目标语言默认中文；已有用户明确保存的服务选择继续保留。
6. 保持桌面端一行布局，在窄屏上按相同顺序堆叠，不产生横向溢出。

### 非目标

- 本次不重写字幕识别、精细转录或翻译后端。
- 本次不增加新的翻译供应商或新的模型。
- 本次不改变实时稿、精细稿和译文的本地存储结构。
- 本次不删除“翻译整节课”和“重试失败段落”，只将低频操作收进更多操作区。

## 设计

### 1. 详情页层级

课堂标题和原声播放器保持现有位置。原声播放器之后直接放置一行 `review-tools-row`，包含两个等高模块：

#### 字幕版本模块

- 标题：`字幕版本`
- 主控：`实时稿 | 精细稿` 分段切换
- 未生成精细稿时：精细稿为禁用态，并显示紧凑主按钮 `开始精细转录`
- 处理中：按钮变为忙碌态，显示进度和“仍可使用实时稿”
- 完成后：精细稿解锁，页面自动切换到精细稿，状态显示 `精细稿已就绪`
- 仍可切换回实时稿，不覆盖实时稿

#### 翻译模块

- 标题：`翻译`
- 默认摘要：`中文 · 快速翻译 · Microsoft Translator`
- 主要操作：`翻译选中段落`
- 没有选择字幕时：按钮保持可见但显示明确提示 `先选择字幕`
- `翻译整节课`、`重试失败段落`、翻译模式、服务商、模型方式收进 `更多` 操作区
- 快速翻译默认目标为中文，默认服务为 Microsoft Translator

两个模块使用同一套表面样式、圆角、内边距和标题层级。精细转录使用冷灰/浅蓝中性色背景；翻译使用很浅的暖色提示，但不再使用高饱和整块橙色作为背景。

### 2. 字幕列表工具栏

字幕区标题行保留 `TRANSCRIPT / 字幕` 和当前版本说明。用户选择至少一段字幕后，在标题行下方显示批量工具栏：

```text
已选择 3 段     翻译选中     取消选择
```

批量工具栏只在有选择时出现，避免默认占用垂直空间。选择状态只服务于批量翻译，不改变编辑、播放和重点标记行为。

### 3. 每句字幕卡片

每句卡片的头部采用统一的三段结构：

```text
时间戳                              选择   翻译   重点
```

- 时间戳使用现有等宽字体，但提高到与操作文字有明显可读性的字号。
- `选择`使用统一尺寸的复选控件与短标签；勾选后卡片使用非常浅的薄荷色背景和边框。
- `翻译`使用普通次级按钮；没有译文时显示 `翻译`，正在请求时显示 `翻译中`，成功后显示 `已翻译`，失败后显示 `重试`。
- `重点`使用书签/星标图标加短文本；未选中为 `☆ 重点`，选中为 `★ 已标记`，只使用暖琥珀色表示重点，不改变正文颜色。
- 三个操作使用相同的最小高度、字号、焦点环和间距，不再混合无边框文字、窄描边按钮和裸复选框。
- 译文在原文下方以 `译文` 小标签加正文显示，使用低对比度薄荷色边线，不能比英文原文更抢眼。
- NOTE 区域保留在卡片底部，使用较弱的分隔线和提示色，避免与字幕正文竞争。

### 4. 色彩和状态语义

使用现有设计令牌，不引入新的主色：

| 语义 | 视觉处理 |
| --- | --- |
| 可用/完成/选中 | 薄荷绿文字、细边框、极浅背景 |
| 主要动作 | 暖琥珀色实心按钮，仅用于开始精细转录和主要翻译动作 |
| 普通动作 | 米白表面、深墨色文字、灰色细边框 |
| 进行中 | 暖琥珀或中性状态灯 + `处理中` 文字 |
| 失败 | 朱砂红状态灯 + 明确可执行的错误文字 |
| 重点标记 | 暖琥珀文字/背景，不使用薄荷绿 |

所有状态必须同时提供文字，不能只靠颜色区分。按钮 hover、focus-visible、disabled、busy 和成功状态要有一致反馈。

### 5. Microsoft 默认值

- 实时课堂设置的 `translationProvider` 初始值改为 `microsoft`。
- 实时课堂设置中的 Microsoft 选项排在首位并明确显示 `Microsoft Translator`。
- 复习页翻译服务默认选中 `Microsoft Translator`。
- 目标语言保持 `中文`，模式保持 `快速翻译`。
- 已经保存过 Google 的用户选择视为明确偏好，继续使用 Google；无保存偏好的新用户使用 Microsoft。
- 翻译状态和错误信息必须显示实际使用的服务，避免页面显示 Microsoft 但请求落到 Google。

## 交互与数据流

1. 进入已选课堂时，默认显示可用的字幕版本；若精细稿已就绪则直接显示精细稿。
2. 点击 `开始精细转录` 后，使用现有原声上传和轮询流程，工具模块显示进度。
3. 精细转录返回 ready 后，保存 `refinedSegments`，设置 `transcriptionMode = refined`，重新渲染字幕并自动切换到精细稿。
4. 切换字幕版本只切换当前阅读源，不删除另一版本；播放定位、导出和搜索继续使用当前源。
5. 选择字幕后，批量工具栏出现；点击翻译后继续复用现有批量队列和本地缓存。
6. 单句翻译只提交当前句，返回结果按 `segment_id` 写回对应卡片，不因重新渲染而插错位置。
7. 翻译失败只影响该句或该批次，按钮变为 `重试`，已成功的译文保留。

## 可访问性与响应式

- 保留按钮、复选框、原生选择框和现有 aria 标签语义；短标签不能取代可访问名称。
- 所有工具控件最小点击高度为 32px，键盘 focus-visible 清晰可见。
- 工具模块在桌面端两列等高，在窄屏端一列堆叠；字幕卡片操作栏允许换行但不覆盖正文。
- 选中、翻译中、失败、精细稿就绪等状态同时通过文本和 `aria-live` 状态节点传达。
- 尊重 `prefers-reduced-motion`，不新增必须依赖动画理解的交互。

## 验收标准

- [ ] 新安装或没有保存偏好时，实时课堂和复习页均默认显示 Microsoft Translator。
- [ ] 已保存 Google 偏好的用户不会被无提示地改掉选择。
- [ ] 精细转录和翻译在桌面端同一行、等高、文字可读，窄屏端无横向溢出。
- [ ] 精细转录完成后自动显示精细稿，实时稿仍可切换。
- [ ] 选择字幕后出现批量工具栏；取消选择后工具栏消失。
- [ ] 每句字幕的选择、翻译、重点操作尺寸一致，选中和完成状态清楚。
- [ ] 单句翻译、批量翻译、重试失败和本地保存行为保持可用。
- [ ] 原有实时稿、精细稿、原声、搜索、播放定位、笔记和导出功能不回归。
- [ ] 通过现有 Python 测试、前端契约测试、JavaScript 语法检查和视觉浏览器检查。

## 证据限制

当前审计环境的复习页没有本地课堂记录，因此空状态可以直接验证；已选课堂的模块和逐句操作以用户提供的当前截图及现有 DOM/CSS 实现为依据。实现完成后需要使用一条真实课堂记录复核“选中课堂、精细稿 ready、选中字幕、翻译成功和失败重试”五个状态。
